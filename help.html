Highlighting

  1. Select some text on any page.
  2. Right-click → Highlight → pick a color (Yellow, Blue, Pink, Green, Orange, Purple).
  3. Or press to use the last color you picked.

To remove highlights: select the text (highlighted or not) → right-click → Remove highlight. Every highlight inside the selection is removed at once.

To undo the last highlight: press , or .

Highlights are not saved — they disappear when the page reloads.

Auto-highlight

With auto-highlight on, text is highlighted as soon as you select it, with no right-click or shortcut needed. It works on every site, including Khan Academy questions.

  1. Click the Lux icon in the browser toolbar. If you don't see it, click the puzzle-piece icon and pin Lux.
  2. Turn on Auto-highlight and pick a color.
  3. Select text. Press to undo the last one.

Text you select inside text boxes is never highlighted. Auto-highlight stays on, in every tab, until you turn it off in the panel.

Why two undo shortcuts?

  • is the natural one. It only acts when there is a Lux highlight to undo and you're not typing in a text box, so the site's own undo keeps working otherwise.
  • is a browser-level shortcut. It always undoes the last Lux highlight, even when the page has focus somewhere unusual.

Why does Mac use Control, not ⌘?

⌘+Shift+H is already Chrome's "Home page" shortcut and ⌘+Shift+Z is Redo in text boxes. The real Control key avoids both conflicts and matches the Windows keys.

Bluebook Mode satquestionbank.org

Makes satquestionbank.org look like College Board's Bluebook app.

  1. Open a question set on satquestionbank.org (use Find Questions).
  2. Click Bluebook Mode in the bottom-right corner.
  3. Use Highlights & Notes, Calculator (math only), Reference and More in the top bar. ABC crosses out answers.
  4. To turn it off: More → Turn off Bluebook Mode.

Troubleshooting

A shortcut doesn't work

Your browser may have given the shortcut to something else, or it was never assigned. Check it here:

Chrome: chrome://extensions/shortcuts · Firefox: about:addons → ⚙ → Manage Extension Shortcuts

Nothing happens on a page that was already open

Reload the page once after installing or updating Lux.

Some pages can't be highlighted

Browsers don't let extensions run on their own pages (like chrome:// pages or the extension store). Highlights can also disappear when a site redraws part of the page, for example after you check an answer.
